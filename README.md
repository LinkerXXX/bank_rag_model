# Система RAG для документации банка

## Описание
Система retrieval-augmented generation (RAG) для поиска и обработки запросов по внутренней документации банка. Решение обеспечивает семантический поиск по векторной базе данных и генерацию ответов с использованием локальной языковой модели.

## Технологический стек
- **Язык:** Python 3.9+
- **Векторная база данных:** Qdrant
- **LLM:** Ollama (модель qwen2.5:3b)
- **Embeddings:** Ollama (модель mxbai-embed-large)
- **Обработка документов:** Docling (опционально), тут используется pypdf, т.к Docling не справился с 100и более страниц
- **HTTP-клиент:** Requests

## Требования
- Установленный и запущенный сервис Ollama (порт 11434)
- Установленный и запущенный сервис Qdrant (порт 6333)
- Загруженные модели Ollama:
  - `qwen2.5:3b`
  - `mxbai-embed-large`

## Установка

1. Клонирование репозитория:
git clone <https://github.com/LinkerXXX/bank_rag_model.git>
cd <project_directory>

2. Клонирование репозитория:
pip install -r requirements.txt

3. Загрузка моделей Ollama:
ollama pull qwen2.5:3b
ollama pull mxbai-embed-large

## Начало работы(база)
1. Папке data/docs размещаем все необходимые документы связанные с дистрибутивом ЦФТ(формат PDF).

2. Запускаем скрпит парсинга: 
python src/baze/main.py
Он распарсит все документы в отдельную папку в формате json.

3. Запускаем скрипт поиска:
python src/baze/main.py
В бесконечном цикле можно будет задавать вопросы модели, пока не будут прописаны команды для остановки: ["конец", "выход"].

## Архитектура работы
1. Пользователь вводит текстовый запрос.
2. Запрос преобразуется в векторное представление (embedding) через Ollama.
3. Выполняется поиск ближайших соседей в коллекции Qdrant.
4. Найденные фрагменты текста формируют контекст.
5. Контекст и исходный запрос передаются в LLM для генерации ответа.
6. Ответ выводится пользователю.
